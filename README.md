# analysis_of_banking_transactions

## Описание

    Приложение для анализа банковских транзакций, генерирует
    JSON данные для вэб-страниц, формирует excel-отчеты, а 
    также предоставляет и другие сервисы, такие как фильтрация операций
    по строке поиска

## Установка:

1. Клонируйте репозиторий:

```
git clone https://github.com/PavelOleynikov/analysis_of_banking_transactions.git
```

2. Установите зависимости:

```
poetry install
```

3. Активируйте виртуальное окружение:

```
poetry shell
```

4. Запустите приложение:

```
python main.py
```

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Используйте функцию, которая получает дату и время
   и возвращает json-ответ с операциями за указанный период

### Примеры входных данных:

Валюты и акции для отображения на веб-страницах
задаются в отдельном файле пользовательских настроек
user_settings.json

Пример:

{
"user_currencies": ["USD", "EUR"],
"user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}

## Как запустить тесты:

    1. Сохраните тесты в файле 
    2. Установите pytest, если не установлен:
       poetry add pytest
    3. Запустите тесты:
       например: pytest tests/test_services.py -v

## Функции в проекте:

    1. main_page
    """функция получает дату и время и возвращает 
       json-ответ с операциями за указанный период"""

    2. current_time_greeting
    """функция возвращает приветствие исходя из 
       времени суток"""

    3. get_slice_data
    """преобразует формат и возвращает список среза дат
       от 01 числа месяца до указанного"""

    4. get_cut_from_excel
    """читает файл xlsx и фильтрует операции 
       за выбранный период"""

    5. get_card_with_spent
    """функция возвращает список карт с расходами и 
       кэшбэком"""

    6. get_transactions_by_pay
    """функция возвращает ТОП-5 транзакций по сумме 
       платежа"""

    7. get_currency_rates
    """функция возвращает текущий курс заданных валют
       в рублях через внешний API"""

    8. get_stock_prices
    """функция возвращает стоимость акций из S&P500
       в рублях через внешний API"""

    9. service_search
    """функция фильтрации операций по строке поиска"""

    10. write_to_file(filename=None):
    """Декоратор для функций-отчетов, который записывает
       в файл результат работы функции, формирующей отчет.
       Если задан filename, принимает имя файла 
       в качестве параметра."""

    11. spending_by_category(transactions: pd.DataFrame, category: str, date: Optional[str] = None) -> pd.DataFrame:
    """Функция возвращает траты по заданной категории
       за последние три месяца (от переданной даты)."""
    
    17. main
    """основная функция, которая запускает проект
       и отвечает за логику программы"""
